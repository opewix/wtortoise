# WTortoise — Git из контекстного меню Finder, в духе TortoiseGit

Цель: то, чем TortoiseGit удобен в Windows, — на macOS. Правой кнопкой по папке или файлу в Finder →
команда → небольшое окно, которое делает одно дело: фиксация, журнал, сравнение, отправка.
Отдельного «большого» окна хранилища нет: проводник и есть обозреватель.

## Решения

- **Стек:** Swift + AppKit, SwiftPM без Xcode, как у WExplorer, WTaskbar и WPhoto. `scripts/bundle.sh`
  собирает `build/WTortoise.app`, `scripts/make-dmg.sh` — образ.
- **Две части в одном `.app`:**
  - приложение (`Sources/WTortoise`) — все окна; своего состояния не держит, закрыл последнее окно — вышло;
  - расширение Finder (`Sources/WTortoiseFinder`, `Contents/PlugIns/WTortoiseFinder.appex`) — меню и
    значки. Само ничего не меняет: пункт меню открывает приложение ссылкой `wtortoise://команда?path=…`.
- **Расширение собирает `swiftc` напрямую** (в `bundle.sh`), не SwiftPM: ему нужна точка входа
  `NSExtensionMain`. Общий код — `Sources/WTortoise/Shared` (команды, значки, поиск `.git`),
  компилируется в обе части.
- **Песочница расширения** обязательна для Finder. Права (`scripts/finder.entitlements`): чтение
  всего диска — найти `.git` и выполнить `git status`. Подпись ad-hoc; Finder такое расширение
  принимает (проверено 19.11.2026 на macOS 26).
- **Git — настоящий:** все действия выполняет установленный `git` (Homebrew, иначе системный; путь
  меняется в настройках). Поведение совпадает с командной строкой, ключи и связка ключей работают
  как в терминале. Своей реализации формата хранилища нет.
- **Вопросы git и ssh** (пароль, фраза ключа, отпечаток узла) задаёт сама программа:
  `GIT_ASKPASS` / `SSH_ASKPASS` указывают на `Resources/askpass.sh`, тот зовёт `WTortoise -askpass`.
- **Фиксация берёт только отмеченные файлы** (`git commit --only -- пути`), что бы ни лежало в
  индексе; файлы не под версией перед этим добавляются. Посреди слияния git такого не разрешает —
  тогда отмеченное кладётся в индекс и фиксируется всё.
- **Долгие команды** идут через окно хода (`ProgressController`): вывод git по мере работы, `\r`
  переписывает строку (проценты передачи), по окончании — уведомление `Git.changed`, по которому
  открытые окна перечитывают хранилище.
- **Журнал:** до 3000 фиксаций, граф раскладывается по дорожкам в `Git.graph`. При отборе по пути
  или по строке поиска граф не рисуется — родители в выдаче идут не подряд.
- **Сравнение:** `git diff -U100000` одного файла разбирается в строки «было / стало»
  (`DiffParser`), рисуется своим видом (`DiffView`) — только видимые строки.
- **Значки состояния:** расширение спрашивает `git status` и держит ответ 4 секунды на хранилище;
  открытие папки в Finder сбрасывает его. Файлы не под версией и игнорируемые — без значка.
- **Графика своя:** значки команд и состояния рисуются кодом в `Shared/Glyphs.swift`, иконка
  программы — в `scripts/appicon` (черепаха оттуда же).
- **Язык:** по умолчанию английский при любом языке системы; русский включается в настройках
  (ключ `language`, действует после перезапуска). Расширение Finder читает выбор из файла настроек
  приложения — у него в песочнице настройки свои.
- **Английские тексты — как в TortoiseGit:** пункты меню, заголовки окон, подписи и кнопки сверены с
  его английскими ресурсами (`resourceshell.rc`, `TortoiseProcENG.rc`, 19.11.2026), в том числе три
  точки `...` вместо `…` и «Git » перед пунктами вне группы. Своё — только там, где у оригинала нет
  соответствия (главное окно, пояснения, «Rebase» в окне Pull). Русские — наш перевод.
- **Значки команд — свои, в манере оригинала** (те же образы: зелёная стрелка фиксации, «пластырь»
  сравнения, жёлтый бочонок хранилища, синяя вилка со звездой…). Значки TortoiseGit не взяты: они под
  GPL, проект под MIT. `scripts/menuicons` при сборке кладёт их в `Resources/MenuIcons/<команда>.png`
  — оттуда их берёт меню WExplorer.
- **Вид окон:** обычные элементы AppKit в светлой теме, раскладка и названия — как в TortoiseGit.
  Цвета строк те же: изменён — синий, добавлен — лиловый, удалён — бордовый; ярлыки веток в журнале
  и цвета сравнения — как в оригинале.
- **Проверка вида:** `WTortoise -snapshot <папка> -path <рабочая копия>` — окна в PNG.
